# Сайт частной стоматологии (шаблон)

Статический сайт на HTML, CSS и JavaScript без сборки. Запись, обратный звонок, прайс с калькулятором, врачи, вопросы, контакты, политика конфиденциальности.

## Быстрый старт
Открой `index.html` в браузере.

## Как сделать сайт для клиники
1. `js/data.js`: замени все данные и настройки. Пока `demo: true`, сверху показывается плашка о заглушках.
2. `css/styles.css`: цвета в блоке `:root` в начале файла.
3. `assets/favicon.svg`: логотип.
4. Дальше следуй `DEPLOY.md` (юридическая часть, заявки, публикация, домен, чек-лист).

## Документы
- `docs/PLAN.md`: план и список функций
- `docs/ARCHITECTURE.md`: архитектура и решения
- `DEPLOY.md`: что сделать для запуска
