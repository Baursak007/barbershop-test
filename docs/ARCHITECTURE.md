# Архитектура

## Принцип
Статический сайт без сборки: HTML, CSS, JavaScript. Хостинг бесплатный (GitHub Pages, Cloudflare Pages или Netlify). Весь контент в одном файле.

## Структура
```
dental-site/
├── index.html          главная страница (пустые контейнеры)
├── privacy.html        политика конфиденциальности (шаблон)
├── 404.html            страница «не найдено»
├── robots.txt
├── sitemap.xml
├── .nojekyll           чтобы GitHub Pages не обрабатывал файлы лишний раз
├── .gitignore
├── css/styles.css      токены, макет, адаптив
├── js/
│   ├── data.js         ВЕСЬ контент и настройки клиники
│   └── app.js          отрисовка, фильтры, калькулятор, форма, аналитика
├── assets/favicon.svg
└── docs/               PLAN.md, ARCHITECTURE.md
```

## Поток данных
```
data.js: CONFIG + SITE_DATA
        │
        ▼
app.js ─ render ─► блоки страницы (пустые блоки скрываются)
   │
   ├─ concerns ──► открывает запись с темой
   ├─ catalog ───► услуги и прайс ──► калькулятор (Set выбранных id)
   ├─ hours ─────► статус «Открыто сейчас» (время Астаны)
   ├─ form ──────► проверка ──► (formEndpoint?) ──► иначе WhatsApp/Telegram
   └─ JSON-LD ───► микроразметка Dentist для поисковиков
```

## Форма записи
1. Проверки на странице: имя, телефон (нормализуется к `+7XXXXXXXXXX`), согласие обязательно.
2. Скрытое поле-ловушка для простых ботов.
3. Если в `CONFIG.formEndpoint` указан адрес, заявка уходит туда как JSON. Если ответ не пришёл, показывается кнопка «Открыть чат» как запасной путь.
4. Если адрес не указан, открывается WhatsApp или Telegram с готовым текстом, остаётся нажать «Отправить».

Честное ограничение: ссылка на мессенджер теряет заявку, если человек не нажал «Отправить». Для боевого запуска лучше поставить `formEndpoint` на твой небольшой сервер или бота, который присылает заявку администратору.

## Безопасность
- Секретов в сайте нет и быть не должно. Токен Telegram-бота, ключи и пароли хранятся только на сервере.
- Вся динамика выводится через экранирование (`esc`), опасный HTML не вставляется.
- Медицинские данные в форму не собираем: в форме есть предупреждение не писать диагноз и паспортные данные.
- Внешние ресурсы: Google Fonts и, если включена, Яндекс Метрика. Об этом нужно сказать в политике конфиденциальности.

## Решения
| Решение | Почему | Цена |
|---|---|---|
| Без фреймворка | Просто, быстро, нечего ломать | Нет компонентов |
| Контент в `data.js` | Шаблон под любую клинику правкой одного файла | Поисковик видит текст после выполнения JS; Google его выполняет, но статичный HTML надёжнее |
| Блоки скрываются при пустых данных | Нет риска показать выдуманных врачей и отзывы | Нужно не забыть заполнить |
| Калькулятор показывает «от» | Честнее, чем точная цена до осмотра | Это ориентир, а не смета |
| Демо-плашка | Не даст выложить заглушки как настоящие данные | Нужно выключить при запуске |

## Дизайн
- Палитра: хвойный тёмно-зелёный `#10302F`, фарфоровый фон `#F6F8F7`, бирюзовая кнопка `#0B6B67`, мятный `#DCEFEA`.
- Шрифты: Geologica (заголовки) и Golos Text (текст), оба с кириллицей.
- Один выразительный элемент: плитки «Что вас беспокоит?» в главном экране. Остальное спокойное, без иконок-украшений.

## Куда развивать
1. RU/KZ переключатель: тексты в `data.js` по языкам.
2. Свой сервер или бот для приёма заявок (это твой продукт).
3. Предварительный рендер HTML (например, Astro) для лучшего SEO, когда сайтов станет много.
4. Страницы услуг и блог для поиска по запросам вроде «имплантация зубов Астана».
